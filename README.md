# NAS Salvage

Windows app that brings back photos, videos and documents from a Synology NAS hit by ransomware.
Free scan; the NAS is only read; nothing is uploaded.

- Website and download: https://nassalvage.com
- Installers: see [Releases](../../releases)
- Scoop: `scoop bucket add nassalvage https://github.com/hypercasting/nassalvage` then `scoop install nassalvage`
- winget: `winget install NASSalvage.NASSalvage`

This repository holds release files and package manifests only (the program is not open source).
Not affiliated with Synology.
